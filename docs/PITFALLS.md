# 坑单（AI 驱动 PCB 设计必须知道）
按"踩一次记一条"的顺序：

1. **`modify()` 改线宽/孔径，DRC 不认几何** → 必须「删除 + 按新参数重建」；改完 DRC 仍按旧几何判定，会造成假通过/假违规。
2. **新铜不会自动进连通图** → 加/删铜后必须 `save + 关标签 + 重开`（MCP `sync_current_document`）。否则"连接错误"读数是旧的（实测：519 → 37）。
3. **孔到孔规则（≥11.8mil / 0.3mm）同网也查** → 挪过孔时必须对所有孔（含同网、含通孔焊盘钻孔）校验，否则补的并联孔会互相违规。
4. **通孔焊盘的"钻孔"必须参与建模** → 只当铜面处理会把新孔放到焊盘孔上（实测 0.00mil 违规）。
5. **反复调 `rebuildCopperRegion()` 会抹掉铺铜** → 每块铺铜只调一次；若已丢，用 `pour_top.js` 这类"只补缺的那块"脚本重建。
6. **手动布线/改件极易丢失 TOP 层铺铜** → 每次人工改动后先重灌铜再 DRC；症状是"4 个 GND 焊盘突然未连接"。
7. **矩形焊盘必须用精确旋转框距**（`hypot(max(qx,0),max(qy,0)) + min(max(qx,qy),0)`），**不能用对角线半径** —— 用错会把 190.9mil 的方盘当成 r=135mil 的圆，导致"每段线都被判死""找不到孔位"等一堆假结论。
8. **A* 开放列表必须用二叉堆，障碍必须先按局部区域预筛** —— 线性扫描版会锁死 EasyEDA 主线程；全板 1900 条线不做预筛会让扫格超时被看门狗返回 HTTP 500。
9. **Freerouting 不检查"孔到孔"**（那是制造规则，不在 DSN 几何约束里）→ 想靠"换 padstack 重跑布线"解决孔间距是徒劳；要真解决得调 DSN 的间距约束或做局部重布。
10. **立创国际站价格是美元**；MCP `component_search` 返回的 `price` 也是美元 → 别拿它直接跟人民币数字比（差 6.7 倍）。
11. **Gerber 不含叠层/压合顺序**（格式本身没有）→ 必须在下单页显式指定，并在包里放 `STACKUP_README.txt`（内层 G1/G2 不可互换）。
12. **通道会掉**：桥接是**独立 Node 进程**（EasyEDA 重启后需重新启用扩展）；MCP 通道与桥接互相独立，可互为备份。
13. **SES/DSN 交换格式的厂商导出缺陷**：内层 wire 层号写成数字会被 FR 丢弃；板框退化成自交多边形；**完全不导 keepout**；多边形重复顶点导致焊盘形状构造失败（该网永不布线）。
14. **判据不能用"是否报岛"** —— 一个尚未连到远端的测试结构会被合法地报成岛；唯一可靠的判据是**该网的连接错误数下降**。

## 环境与通道
17. **`run-api-gateway` 扩展不会自动重试** —— 它只在扩展加载的那一刻扫端口连接；若那时桥接没起来(或 EDA 后启动)，就必须**手动点一次「重新连接」**。
    规避：**先起桥接、再开 EDA**（用 `tools/bridge-watchdog.py` 或 `start-bridge.cmd`）；工具侧用 `/health` 的 `edaConnected` 字段先自检再动手。
18. **中文路径经 argv 传入 Python 会乱码** —— 报 `FileNotFoundError` 但文件确实存在。
    修法：注入 `PYTHONUTF8=1`；工具内做路径自愈；最稳是路径写在 UTF-8 配置/源码里，不走命令行参数。
19. **工具里别硬编码项目路径** —— 统一 `<项目>/design/`（设计侧）与 `<项目>/deliver/`（交付侧）约定 + 命令行可覆盖。

## 自检与度量
20. **焊盘 `rotation` 是"弧度", 不是度** ★★ —— `getAll()` 返回的对象里 `rotation: -1.5707963267948966` 就是精确的 −π/2 (90°)。
    踩坑记录：按"度"处理时, 90° 旋转的 `["OVAL",24.8,88.6]` 长条焊盘会被当成竖着→阻挡区方向整个转反 ✗
    后果：密集区会出现"明明没挡却判挡住/A* 找不到路"的鬼故事。**修法：`rot = p.rotation`（直接用），不要 ×π/180**。
    自查方法：拿本板既有连线的中点做正向对照(本网必须判"畅通"), 修前 85/101, 修后 101/101。
21. **自己写的指标别用魔法哨兵值** —— `minHH===1e9 ? -1 : minHH` 里的 `-1` 会和"真实负余量"混淆,
    我因此把一块合格板(最小孔间距 12.3mil=0.312mm)误报成"差 1mil 不达标" ✗。
    修法：哨兵值用 `null` 或独立字段；关键指标直接用**暴力全对全**算真值, 不要靠"最紧约束是谁"去反推。
22. **几何模型必须做"正反成对"自检** —— 只做"不能放的地方要判非法"会漏掉"过度保守"(把好位置判死),
    而过度保守的表现是"布线器什么都布不出来", 很难和"真的布不下"区分。
    正反成对写法：同一批点, 本网判畅通(正向) + 换个不存在的网名判被挡(反向), 两边都要过。

## 通道与状态
23. **重 API 调用会锁死 EDA 主线程, 而且救不回来** ★★ —— 实测踩到两次(A* 线性扫描一次, 原理图 `getCurrentProjectAllNets()`/`sch_PrimitivePin.getAll()` 一次)。
    现象：桥接 `/health` 里 `pendingRequests` 一直 >=1 不降; 后续请求全部 HTTP 500; 连 MCP 通道也开始返回空(`get_pcb_stack_layers` → `layers: []`)。
    恢复：**只能由人刷新 EasyEDA 编辑器页面(F5)**。桥接进程重启没用 —— 卡住的是 EDA 侧的 JS, 不是 Node 侧。
    预防：① 别调"全项目/全页对象"级 API(`getCurrentProjectAllNets`、全量 pins、`getAll()` 之后还要遍历计算的大活);
          ② 先取数量再决定要不要取细节; ③ 大计算前先存 checkpoint(这样重载也不丢东西);
          ④ 设计成"每步小而快", 超时阈值给小(30s), 超时立刻停手, 别连着重试。

24. **当前活动文档决定 API 有没有数据** —— `eda.sch_*` 只在原理图 tab 激活时有效, `eda.pcb_*` 只在 PCB tab 激活时有效;
    拿错了不报错, 只返回 **空数组**(很容易误判成"这个设计没有网络")。
    要用 MCP `open_document` 切页签时注意: 传 **页 uuid**(Schematic Page), 传原理图顶层 uuid 会 `Failed to open document`。

25. **原理图被改动后, DRC 会出现 `Netlist Error / Import Changes`** —— 它没有坐标、`id=err0/err1/err2`, 属于"PCB 尚未同步原理图"的提示, **不是制造缺陷**, 但也绝对不是 0 违规。
    报数时要说清是"3 条同步提示 + 0 条布线违规", 不能笼统说"DRC 0 违规"。
    同步(导入变更)前必须存档: 导入会按新网表删/改对应网络的铜, 可能把已布好的线带走。

## 变更/换料
26. **`pcb_Net.getNetlist()` 不携带"元件实例值"** —— 原理图改过元件值、PCB 也"导入变更"成功了,
    但导入前后这份网表**字节完全相同**(229994 字符, md5 一致)。拿它做"值 diff"会得到**假阴性**:
    误判成"属性没变" ✗。取真值要走 **BOM 导出**(Export_BOM.xlsx / BOM_修正版.csv)。
27. **`pcb_PrimitiveComponent.name` 不是元件的值** —— 它返回显示表达式 `={Value}` ✗。
    别拿它当 Value 去比对, 会得到一堆"值全都没变"的废话。元件实例值请从 BOM 导出或网表 props 取。
28. **DRC 里的 `Netlist Error / Import Changes`(无坐标, id=err0/1/2)** = PCB 与原理图不同步,
    不是制造缺陷, 但也**绝不能**算进"0 违规"。处理流程见 `docs/ECO_CHANGE.md`;
    报数时必须写清"0 条布线违规 + N 条同步提示"。
29. **不许靠型号字母猜规格** ★ —— 我按"FC-135R 的 R 就是 7pF"推断, 实测该料(Q13FC13500004/C32346)
    是 **12.5pF** ✗, 差点把超规格的料当合格料放行。**必须**抓立创页面结构化字段核验:
    `python pcbai.py lcsc --file page.html --fp SMD3215-2P --need "Load Capacitance=7pF" --need "ESR<=70k"`
    (国际页走 JSON-LD+PropertyValue, 国内页走 __NEXT_DATA__ 的 parameterName/parameterValue, 工具两种都吃)
