# 布线全流程（9 个阶段）

以 `case/` 这块 90×90mm 四层板为例。每个阶段都写清楚：**做什么 → 用什么 → 当时的坑**。
原则只有一条：**每改一类东西，就立刻用可复算的判据证明没把别的弄坏**；证明不了就不算改完。

---

## 阶段 0 · 约束先行（不要先画线）

先定死这些，后面所有自动化才有意义：

| 约束 | 取值 | 为什么 |
|---|---|---|
| 安全间距 | 6 mil（板规） | 板厂能做的常见档，也留够余量的下限 |
| 过孔 | 16/12 mil（0.4064/0.3048 mm） | **免加钱档 0.3mm 钻**；环宽 0.051mm |
| 线宽 | 信号 6–10 mil，电源/电机相线加粗到 25 mil | 电机相线要过流 |
| 平面 | 内1 = **GND**、内2 = **VCC**，顺序不可换 | 与板厂层压结构绑定（7628 半固化片，10mil 线 ≈52–55Ω） |
| 禁布区 | 滚轮挖空、天线净空（8.0×3.0mm 全层）、电机圆（TOP） | 结构 + 射频硬约束 |

> 坑：**规则要用"网络类"批量设**，别一条条点。反过来，工具注入的临时规则（本项目曾注入 379 条
> `copilot_router_*`）会污染净规则列表 → DRC 直接爆 1400 条错误。改完必须复查残留=0。

## 阶段 1 · 放置（几何先验证，再动手）

- 锁死件先钉住：按键 SW1..SW13、编码器 U5、磁吸/结构件 H1/H2/H4/H5、USB1、CN1、天线网络。
- 用脚本做**几何校验**（`place_verify.py` 的 R1–R7）：元件间最小间距、焊盘到焊盘、离挖空区、离板边。
- 校验器必须用**精确旋转框距**：

```js
// 矩形焊盘到点距离：先转到焊盘局部坐标，再算精确框距
const qx = Math.abs(dx) - a/2, qy = Math.abs(dy) - b/2;
dist = Math.hypot(Math.max(qx,0), Math.max(qy,0)) + Math.min(Math.max(qx,qy), 0);
```

> 坑（两次踩）：**不许用对角线当半径**。曾把 190.9mil 的 GND 焊盘当成 r=135mil 的圆，
> 于是"到处都放不下"，实际有余量。另外 **焊盘 `rotation` 是弧度**，按度数处理会把阻挡区转反。

## 阶段 2 · 全局自动布线（Freerouting 流水线）

1. **导出 DSN**（`python pcbai.py dsn`）：这一环节本身有缺陷，必须先修好再喂给布线器：
   - ★ 走线写的是 `(path 1 …)`/`(path 2 …)`，而头部声明的层名是 `TopLayer/BottomLayer`
     → Freerouting 找不到层名，会把**已有铜全部丢掉**（等于从头布）；导出器自动补成层名
     （早先按数值层号硬喂的那一版，直接丢了 319 条线）
   - 板框退化成 5–6 点自交多边形 → 补点重排
   - **完全没有禁布区** → 手动把挖空/净空写进 DSN
2. **跑 Freerouting**（`python pcbai.py fr run --dsn … --ses … --passes 30 --oi 0.25 --poll`）：
   `freerouting-2.4.1.jar`(62MB, GPL-3.0, 用 `pcbai.py fr install` 按需下载) + JDK 25
   `-de in.dsn -do out.ses -mp 40 -oit 0.25`
   > 坑：必须用 `Start-Process` 起；当后台任务起会被中断。FR **不检查孔到孔**。
3. **导入 SES**：导入器有 4 个坑，导入后必须依次补：
   - 忽略 SES 里的线宽 → `restore_widths.py --apply`
   - 内层铜落到 21/22 层 → `fix_layers.js`（21→15，22→16）
   - 忽略 SES 的过孔盘径 → 全部 24/12mil，需按 SES 重建
   - 新图元不会自动进连通图 → `sync_current_document`（一次同步把 519 条悬空降到 37 条）

> 判据：**导入后立刻重跑 DRC**，违规数只能降不能升；升了说明导入器又坑你了。

> 完整手册（参数表 / 导入器四个坑 / 验证闭环 / 许可证注意）见 **`../docs/FREEROUTING.md`**。

## 阶段 3 · 补线（A\* + 分阶段推进）

- 用 `tools/geom_router.js`（几何引擎 + 单层 A\*）：精确框距、孔到孔（同网也查）、二叉堆防止锁死主线程。
- 分阶段小步走（`route_stage1..9*.js`），每阶段只解决一类网络（先电源、再电机相线、再 RF、最后补零散）。
- 过孔不是"随便打"：先 `placeVia()` 找到有净空、且**仍压住本网铜**的位置，再创建。
- 房间不够时的正确顺序：**加宽线 → 挪过孔 → 改层 → 换更小钻孔（最后手段）**。

> 坑：A\* 用线性扫描开放列表会**冻死 EDA 主线程**（只能人工重启）→ 必须二叉堆 + 局部障碍预筛。
> 坑：改线后要检查**各层的悬空端**：只在顶层补线，会把内层的连接扯断（曾一次断 5 处）。

## 阶段 4 · 铺铜

- 4 块铺铜：TOP/BOTTOM 为 GND，内1 GND，内2 VCC。
- **重建铺铜要"每块一次、中间留间隔"**：

```bash
python pcbai.py repour          # 内部：对每块 pour 只调用一次 rebuildCopperRegion()
```

> 坑：反复 `rebuildCopperRegion()` 会把铺铜**整个删掉**（曾一次丢 4 块，只能回滚）。

## 阶段 5 · DRC 归零（要用全量导出，不要看界面）

```bash
python pcbai.py drc             # 3 次采样并集去重 + 覆盖率自证(100%)
python pcbai.py drc --limit 0   # 导出全部条目
```

- 按 **类别 → 规则名** 分组修，一次修一类，修完复跑。
- 1400 条错误的根因案例：**规则被注入 379 条 net-rule**，不是布线本身的问题。
- 孔到孔 12 条 → 通过局部挪过孔压到 3 条（0.272/0.279/0.287mm）→ 最后 1 条由人工布线解决。
- **口径**：如果出现 `Netlist Error / Import Changes`（无坐标、id=err0/1/2），那是"PCB 与原理图不同步"，
  报数必须写成「0 条布线违规 + N 条同步提示」，不能笼统说 0 违规。

## 阶段 6 · 可制造性复核（投板前必做）

```bash
python pcbai.py holes           # 全板钻孔：孔到孔/孔径/环宽，暴力全对全
```

实测：331 个孔、54615 对全扫 → 最小孔到孔 **0.312mm** ✓、最小钻 **0.305mm** ✓、最小环宽 0.051mm ✓。

> 坑：孔到孔**同网也要查**（同网两个孔挨太近，钻头一样会断）。厂规按 0.25mm 留余量。

## 阶段 7 · Mark 点（贴片对位）

- 用**库里的** mark 点器件（`Mark-Point-1mm`），**不要自己画**：库件带正确的焊盘与库属性。
- 但库件通常只带 Ø1.1mm 的小开窗、**不带周边禁铜** → 要自己补：
  1. 用 Ø2.0mm 开窗图元把开窗顶到标准尺寸
  2. 加 2.2×2.2mm 多层禁布区，保证开窗内形成 ≥0.5mm 无铜环
- **位置用扫描选**，不要拍脑袋：全板网格扫描，要求两层铜净空、离板边 ≥5mm、避开挖空/净空区、
  离器件 ≥4mm，最后挑 3 个互相 ≥25mm 且不对称的点。
- 库件是"器件" → 设 `加入BOM = 否`（BOM 保持 166 项不受污染）。

## 阶段 8 · 交付

```bash
python pcbai.py export gerber bom pickplace
```

- Gerber zip 里**必须附叠层与层压说明**（Gerber 格式本身不携带层压信息，板厂看不到就得问）。
- 交付清单：Gerber+钻孔、BOM、贴片坐标、单板装配清单、BOM 对账表、给贴片厂的工艺要求。
- 所有结论用实测数字写（天线净空 8.0×5.5mm 实测、最小孔径、环宽…），不写"应该没问题"。

## 阶段 9 · 变更与换料

原理图一改，PCB 就与它不同步（DRC 出现同步提示）。完整流程见 `../docs/ECO_CHANGE.md`，
核心是**导入前后各存一次基线，用铜量 diff 证明没删铜**：

```bash
python pcbai.py inv   && cp _pcb_net_inventory.json snapshots/inventory_before.json
# …导入变更（必须人工确认）…
python pcbai.py inv && python pcbai.py invdiff snapshots/inventory_before.json _pcb_net_inventory.json
python pcbai.py drc
```

## 一句话总结

**先定约束 → 几何验证放置 → 自动布线 + 逐类补线 → 分层铺铜 → 全量 DRC 归零 → 可制造性复核 → 交付 →
变更走 ECO。** 每一步都要有一个"跑一次就能复现"的判据，否则不出手。
